Use in WWW

CDN Example

Instructions

This example shows how to integrate and use JM2MP and JM2MP.JS in any static or dynamic web page without installing the corresponding package, just linking to a Content Delivery Network (CDN) like jsDelivr or GitHub's raw user content.

Please, inspect the source code of this page to better understand the mechanism involved. You will see a <script> HTML element that reference a JavaScript file containing an ESM module where all the code resides.

Below, you can see a source JSON document, a projection JM2MP document and then, the resultant JSON document transformed directly in your browser.

Please, refer to the Use in WWW tutorial for more information about this example.
